# Final Days 비공식 한글 패치

Final Days의 영어 UI와 게임 플레이 문구를 한국어로 바꾸는 비공식 팬 패치입니다. 이 게임은 별도 언어 선택 기능이 없으므로 영어를 한국어로 교체합니다. 번역문은 GPT가 영어 원문을 기준으로 직접 작성했습니다.

## 다운로드

[최신 패치 다운로드](../../releases/latest/download/Final-Days-Korean-v1.0.1.zip)

오른쪽의 **Releases**에서 `Final-Days-Korean-v1.0.1.zip`을 받을 수도 있습니다. GitHub가 자동으로 제공하는 `Source code.zip`은 설치용 한글 패치가 아닙니다.

현재 패치 버전: **1.0.1**

## 지원 버전

- Steam Build ID: `14005084`
- 게임 버전: `1.2.2.2`
- 게임 업데이트로 Build ID가 달라지면 최신 한글 패치가 필요할 수 있습니다.

## 설치 방법

1. Final Days와 Steam을 종료합니다.
2. 다운로드한 ZIP을 완전히 압축 해제합니다.
3. `Final-Days-Korean-Patcher.exe`를 실행합니다.
4. `1: 설치`를 선택합니다.
5. Final Days를 실행합니다. 별도 언어 설정 없이 한국어가 적용됩니다.

같은 한글 패치의 이전 버전이 설치되어 있으면 사용자가 먼저 복구할 필요가 없습니다. 설치기가 기존 설치 정보와 파일 해시를 확인하고 원본을 안전하게 복구한 뒤 새 버전을 설치합니다.

Steam 설치 위치를 자동으로 찾지 못하면 `FinalDays.exe`가 있는 게임 폴더를 직접 입력해 주세요.

## 삭제 및 원복

1. Final Days와 Steam을 종료합니다.
2. 같은 설치기를 실행합니다.
3. `2: 원본 복구`를 선택합니다.

설치기가 만든 `FinalDays_Korean_Backup` 폴더에는 원복에 필요한 개인용 백업이 있으므로, 원복 전에는 지우지 마세요. 게임 저장 데이터와 계정 설정은 수정하지 않습니다.

## 번역 범위

- 메인 메뉴, 게임 생성·참가, 설정, 조작키, 도움말과 일시 정지 메뉴
- 캠페인·모드·난이도 이름과 설명
- 임무 목표, 공세·층·구역 진행 문구와 완료 메시지
- 맵 표시 이름과 잠금 해제 조건
- 무기·탄약·폭발물·보급품 이름
- HUD, 점수표, 순위표, 부활·상호작용·처치 알림
- 서버가 생성해 클라이언트에 전송하는 임무 및 플레이어 상태 문구
- Steam 창작마당, 피드백, 업데이트 및 주요 오류 안내
- 키보드·게임패드·Steam 컨트롤러 입력 이름과 보너스 점수 문구
- 전용 서버 설정 창, 서버 통계와 오류 대화상자
- 제작진 화면의 제목·소개·감사 문구(라이선스 고지 원문은 보존)
- 동적 본문 글꼴과 정적 제목 글꼴 경로의 한글 글꼴 적용
- 번역에 사용된 한글 475자를 시작 시 한 번 동적 글꼴에 등록해 메뉴·HUD의 `?` 표시 방지

번역 데이터는 중복 없는 884개이며, 그중 실제 원본에 사용된 844개가 클라이언트·공용·서버 어셈블리의 문자열 명령 1,086곳을 교체합니다. 제작진 텍스트 파일 1개도 이진 차이 방식으로 함께 패치합니다.

## 업데이트 호환성

설치기는 지원 대상 원본 파일의 해시가 정확히 일치할 때만 파일을 변경합니다. Steam 업데이트 후 설치가 거부되면 Steam에서 게임 파일 무결성을 확인하고, 새 Build ID를 지원하는 한글 패치를 기다려 주세요.

한글 패치를 설치한 상태에서 게임이 업데이트되었다면 먼저 설치기의 원본 복구를 시도하세요. 업데이트로 파일이 이미 바뀌어 안전한 복구가 불가능하면 설치기는 작업을 중단합니다.

## 알려진 제한 사항

- 고유 게임명 `Final Days`, 플레이어가 정한 이름, 채팅, Steam에서 제공되는 외부 텍스트는 번역하지 않습니다.
- 개발 로그와 내부 식별자는 게임 동작을 보호하기 위해 번역하지 않았습니다.
- 맵 속성 키, 스프라이트 키, 워크숍 폴더명, 구버전 서버명 파서 같은 실행용 문자열은 화면 문구와 분리해 원문을 유지합니다.
- 일부 짧은 조작키 이름과 숫자·단위는 원문 표기를 유지합니다.
- 게임 안에서 열 수 있는 과거 버전 변경 기록(`Changelog.txt`)은 128KB 분량의 개발 기록이므로 이번 버전에서는 원문을 유지합니다.
- 제작진 화면의 제3자 저작권·라이선스 문장은 법적 의미를 보존하기 위해 영어 원문을 유지합니다.
- ScreenVista Studio로 메인 메뉴를 1분 이상 간격으로 재캡처하고 설정·정보/지원·제작진 화면으로 전환해 한글 유지, 줄바꿈, 배치와 `?` 미표시를 확인했습니다. 글리프 등록은 시작 시 폰트별 1회이며 보이는 문구를 타이머로 반복 덮어쓰지 않습니다.
- 서명되지 않은 개인 제작 설치기이므로 Windows가 게시자를 확인할 수 없다는 안내를 표시할 수 있습니다.

## 배포 방식

배포 ZIP에는 저작권이 있는 원본 게임 파일이나 수정된 완성 게임 어셈블리가 포함되지 않습니다. 설치기는 사용자의 정품 게임 파일 해시를 확인한 뒤 재배포 가능한 이진 차이만 적용합니다.
